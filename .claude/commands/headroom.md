---
description: Facilities drawn close to or above their limit.
---

```sh
npm run lending -- headroom            # 90 percent and above
npm run lending -- headroom --over=80
```

A working capital line pinned at its limit is often the first sign of strain. For each, show the last call note and suggest a conversation.

Every command takes `--json`. Clients match on code, id prefix or part of the name; if the CLI lists several candidates, show them and ask which one. Never answer about a client from memory.
